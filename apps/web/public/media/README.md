# Emplacements média

Déposez ici les photographies du site. Tant qu'un fichier est absent,
l'emplacement affiche une composition générée aux couleurs du territoire :
la mise en page reste complète et aucune reprise de code n'est nécessaire à
la livraison des visuels.

Les noms de fichiers, cadrages, textes alternatifs et briefs de prise de vue
sont déclarés dans `apps/web/src/design-system/media/registry.ts`.

| Fichier attendu | Cadrage | Sujet |
|---|---|---|
| `hero-ville.jpg` | 2400 × 1200 | Vue large de la ville, fin de journée, végétation visible |
| `citoyenne-portrait.jpg` | 900 × 1200 | Personne dans la rue, téléphone en main |
| `equipe-intervention.jpg` | 1600 × 1000 | Agents municipaux sur un chantier de voirie |
| `rue-nuit.jpg` | 1600 × 1000 | Rue résidentielle de nuit, éclairage partiel |
| `berge-fleuve.jpg` | 1600 × 1000 | Berge après la saison des pluies |
| `visage-quartier.jpg` | 800 × 800 | Portrait serré, recadrable en cercle |
| `rue-marche.jpg` | 1000 × 1000 | Rue commerçante animée |

Toute photographie montrant une personne identifiable exige un accord écrit
de cette personne, conservé par la collectivité ou l'organisation cliente.
